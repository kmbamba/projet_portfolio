Application de gestion de tâches

Ce projet est une application de gestion de tâches développée avec HTML, CSS et JavaScript. Elle permet aux utilisateurs de créer, modifier et supprimer des tâches, ainsi que de les classer par priorité ou par date d'échéance. Le design est simple et intuitif, facilitant l'utilisation quotidienne.

Technologies utilisées :

  • HTML
  • CSS
  • JavaScript
